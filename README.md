# Coloring Book for Kids

**Historical short name:** Coloring Book  
**Status:** original browser coloring game  
**Creator:** Joe Nasr  
**Creator identity:** https://joe-nasr-signals.vercel.app/v2/

Coloring Book for Kids is a touch friendly browser coloring game built around direct color selection and SVG drawing regions.

## Gameplay

Players choose colors, fill drawing regions, move through five progressively richer coloring levels and save the current drawing as a JPG.

## Technology

React, TypeScript and Vite. The browser build is prepared for static HTML hosting and itch.io packaging.

Coloring Book and Coloring Book for Kids are the same game lineage. Existing branches and release files are retained as development history.
